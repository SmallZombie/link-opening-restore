# Link Opener
[English](README.md) | [简体中文](README.zh-CN.md)

这是一个 Obsidian 插件，它可以在编辑模式下，恢复链接的打开方式为 <kbd>Ctrl</kbd> + <kbd>左键</kbd>。

**内链快捷键：**

- **<kbd>Ctrl</kbd> + <kbd>左键</kbd>** — 在当前标签页打开
- **<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>左键</kbd>** — 在新标签页打开
- **<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>左键</kbd>** — 在新窗口打开
